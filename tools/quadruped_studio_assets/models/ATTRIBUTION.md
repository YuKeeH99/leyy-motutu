The model has 55,474 rendered triangles, 28,754 vertices, four embedded
textures, nine materials and 19 animation clips. The original GLB is 7,593,852
bytes with SHA-256
`c39e1e4a5ed4e85bb33acaa55a87cf9e4b37a7dff6dc4834658bd207690eb94c`.

The GLB itself was not changed. ARCS Motion Studio applies runtime scaling,
lighting, a restrained `0Idle` animation and four-servo target-pulse joint
visualization around the original model. This is a visual reference for
commanded PWM targets, not servo position feedback, kinematic validation or a
claim that the connected robot is a Unitree product.
